
#  Lista de Contactos do Jean

Este projeto é um sistema simples que serve para guardar e organizar nomes 
e números de telefone no computador. Ele ajuda a encontrar os contactos 
mais rapidamente e evita que fiquem nomes repetidos na lista.

##  Programas Usados

Esta tabela mostra os programas que instalámos no computador para fazer
 o trabalho funcionar:

| Nome do Programa | Para que serve | Versão |
| :--- | :---: | ---: |
| MySQL | Guarda os contactos | 8.0 |
| XAMPP | Faz o sistema funcionar | 8.2 |
| VS Code | Onde escrevemos o texto | 1.85 |

>  **Aviso Importante:** Lembre-se de ligar os botões do programa
 XAMPP antes de começar a mexer na lista de contactos.

##  Como Instalar no seu Computador

Siga estes três passos simples para testar o projeto:

1. Baixe os ficheiros do projeto para o seu computador.
2. Abra a pasta principal onde os ficheiros foram guardados.
3. Ligue o arquivo de códigos para criar a sua lista inicial.

###  Configurações Iniciais

Para o sistema funcionar, usamos este pequeno código de exemplo 
para criar o nosso espaço:

```sql
CREATE DATABASE jean_contatos;
USE jean_contatos;
```
